## Production architecture

AccelRestaurants V2 is a **Firebase-native application**. The production Firebase project is `accelrestaurant-d2c1f`, with Firebase Hosting, Firestore, Authentication, Cloud Storage, Cloud Functions, and the repository's Firebase rules/configuration as the authoritative platform architecture.

## Status of this repository

This repository contains historical prototype source retained only for reference. The obsolete runnable preview application and its obsolete backend/deployment artifacts were removed on September 7, 2026 so they cannot be mistaken for the current application stack.

Do not add production features, database schemas, deployment workflows, or platform integrations here. All current AccelRestaurants development belongs in `AccelRestaurants_V2`.
